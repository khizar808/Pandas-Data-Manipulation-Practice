# Pandas Data Manipulation Practice

A hands-on collection of **Pandas practice notebooks** focused on learning and applying essential techniques for data manipulation and analysis in Python.

This repository documents my learning journey with **Pandas**, from basic Series and DataFrame operations to working with CSV data, selecting data, removing rows/columns, calculating statistics, and applying custom functions.

## 📌 Overview

The notebooks contain practical exercises designed to build a strong foundation in **data manipulation using Pandas**.

The practice includes both small examples and operations performed on a 100-row dataset containing demographic, income, workplace safety, and survey-related attributes.

## 🧠 Topics Covered

* Importing and using Pandas
* Pandas `Series`
* Creating Series with custom indexes
* Series indexing and slicing
* Series arithmetic operations
* Creating Pandas `DataFrame`
* Reading CSV files with `read_csv()`
* Inspecting datasets with:

  * `head()`
  * `tail()`
  * `shape`
  * `describe()`
* Selecting rows and columns
* `loc[]` indexing
* `iloc[]` indexing
* Selecting specific columns
* Dropping columns
* Dropping rows
* Basic statistical operations:

  * `max()`
  * `min()`
  * `mean()`
  * `median()`
* Applying custom functions with `apply()`
* Basic data transformation

